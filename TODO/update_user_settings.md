# Konzipierung einer neu Strukturierung der Einstellungen #

<h3>Anforderungen</h3>

1. Erstelle eine Datei mit einem Plan welcher die in 1.1 gelisteten Anforderungen erfüllt
2. Schreibe durchsuche /doc/IMPLEMENTATION_PLAN.md und suche nach einer geeigneten Stelle um die im Plan definierten veränderungen zu implementiern
3. Gehe sicher, dass die Veränderung /doc/ACCEPTANCE.md bestehen






**1.1**

1. Compliance mit folgenden Datein:
   * /doc/ACCEPTANCE.md
   * /doc/design.md
   * /doc/DECISIONS.md
   * /doc/SECURITY.md
   * /doc/UI_UX_DECISIONS_RUNDE_11.md
   * /doc/UI_UX_SPECIFICATION.md
   
2. Widget basiertes Design für die Einstellungen 

   * Muss anpassbar sein
     * Gewisse Widgets sind verpflichtend für compliance
   * Keine schattierungen oder sonstigen UI features welche nicht in compliance mit 1.1 sind!
